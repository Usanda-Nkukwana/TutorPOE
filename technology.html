Integration of technology

Technology is part of both my ICT background and the programming and database subjects I support.

Technology across both tutoring modules

In both Technical Programming (Java) tutoring in 2025 and Information Systems tutoring in 2026, I used interactive digital tools to support practice, check student understanding, and make learning more engaging.

Quiz.com

I used Quiz.com with students in both modules to provide quiz questions, assess their level of understanding, and make the learning process fun and engaging.

Programiz

For Technical Programming (Java), I used Programiz to run and simulate Java code. For Information Systems, I used it to run and simulate SQL code, helping students practise and see the results of their code.

Purposeful use

Quizzes helped me check understanding in an enjoyable way, while code simulators gave students a place to practise Java and SQL and observe what their code does. I use digital tools to support clear teaching and student interaction, not as a replacement for them.
